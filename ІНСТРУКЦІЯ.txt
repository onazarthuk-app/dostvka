1. ОСНОВНЕ (безкоштовно, тариф Spark)
  1) Firebase Console → проєкт dostavka-ed553 → Authentication → Sign-in method → увімкнути Email/Password.
  2) Realtime Database → Rules → вставити вміст database.rules.json → Publish.
     (Правила оновлені: магазин бачить лише свої заявки, роль «Склад», логіст призначає ролі, телефони клієнтів у захищеному розділі contacts.
      Якщо вставляли старі — обов'язково замініть.)
  3) Залити на хостинг усі файли програми (index.html, sw.js, manifest.webmanifest і всі іконки: favicon.ico,
     favicon-16.png, favicon-32.png, apple-touch-icon.png, icon-192.png, icon-512.png, icon-maskable-192.png, icon-maskable-512.png).
     Старі файли іконок можна замінити — назви ті самі.
     Програма має відкриватися по https (GitHub Pages, Netlify, Firebase Hosting — так і є).
  4) Ще → Налаштування: водії з телефонами, адреса складу, ТЕЛЕФОН ЛОГІСТА (водії бачать кнопку «Логісту»),
     тарифи доставки й підйому, телефон магазину для повідомлень.
  5) Після оновлення адміністратор або логіст один раз відкриває програму: телефони клієнтів зі старих
     доставок автоматично переносяться в захищений розділ (з'явиться повідомлення з замочком).
     До цього моменту старі доставки ще містять номери в загальних даних.

РОЛІ
  Адміністратор — усе. Логіст — доставки, каса, телефони клієнтів, призначає ролі (крім адміністратора).
  Магазин — створює заявки і бачить ЛИШЕ свої заявки й доставки (інші магазини йому не видно навіть у базі),
           без сум. Кожному магазину — окремий акаунт. Водій — свої доставки, без номерів клієнтів, кнопка «Логісту».
  Склад — що зібрати, «Зібрано», «Видано водію», прийом повернень. Без номерів клієнтів і сум.
  Номери клієнтів база взагалі не передає на телефони водіїв і складу, а не лише ховає на екрані.

  Після цього працюють: повідомлення клієнтам, фото й підпис, підйом і доставка в касі, часткова доставка,
  карта водіїв, звуки, офлайн-режим і сповіщення, поки програма відкрита у фоні.

2. PUSH ПРИ ЗАКРИТІЙ ПРОГРАМІ (потрібен тариф Blaze)
  Blaze — оплата за фактом. При вашому обсязі зазвичай 0 грн, бо безкоштовні ліміти великі, але потрібна картка.
  1) Firebase Console → Project settings → Cloud Messaging → Web Push certificates → Generate key pair.
     Скопіювати ключ → у програмі: Ще → «Підтвердження доставки і push» → Ключ Web Push.
  2) На комп'ютері: встановити Node.js 20 і Firebase CLI (npm i -g firebase-tools), потім у теці з архівом:
       firebase login
       firebase use dostavka-ed553
       cd functions && npm install && cd ..
       firebase deploy --only functions
     (У functions/index.js можна вписати APP_URL — адресу програми, щоб сповіщення відкривало її.)
  3) Кожен користувач на своєму телефоні: аватар → «Сповіщення телефону» → Увімкнути.
     На iPhone спершу «Поділитися → На початковий екран», і відкривати програму звідти (iOS 16.4+).

ПІДКАЗКИ
  • Звуки вмикаються/вимикаються в профілі (аватар зліва вгорі), там же можна їх прослухати.
  • Водій передає геопозицію, поки програма відкрита. Вимкнути можна в профілі.
  • Фото зберігаються в базі стиснутими (~100–150 КБ). Безкоштовного 1 ГБ вистачає приблизно на 6–8 тис. фото.
    Старі доставки разом із фото прибирає «Очищення даних за період» (спершу зберігає Excel).
  • Офлайн: якщо зв'язку немає, програма відкривається зі збереженою копією, а зміни відправляються,
    щойно з'явиться інтернет. Не закривайте програму, поки зміни не відправились (зелена точка вгорі справа).

ПОРЯДОК РОБОТИ ІЗ ЗАЯВКАМИ
  1) Магазин (менеджер) натискає «+», заповнює клієнта, адресу, товар і бажану дату → заявка йде логісту.
  2) Логіст бачить заявки червоним контуром (блок «Заявки» на телефоні, колонка «Заявки без часу» на ПК),
     телефонує клієнту, вказує погоджені дату й час і водія → «Зберегти».
  3) Лише після цього склад отримує замовлення на збір, а водій — доставку.
  Магазин бачить статус своєї заявки і отримує сповіщення, коли її погоджено.
  Ролі призначають адміністратор і логіст («Ще → Користувачі»).

КІЛЬКА СКЛАДІВ
  Ще → Налаштування → «Склад і карти» → Склади: назва й адреса кожного складу, ★ робить склад основним.
  У доставці логіст вибирає «Склад відвантаження». Водій бачить у картці «Забрати товар: склад · адреса»
  (натиснув — відкриється маршрут), а «Маршрут дня» стартує зі складу і заїжджає на інші склади, якщо треба.
  Склад бачить на картці, з якого складу замовлення.
