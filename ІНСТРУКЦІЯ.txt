  index.html, sw.js, manifest.webmanifest, іконки  — сама програма (заливається на хостинг)

1. ОСНОВНЕ (безкоштовно, тариф Spark)
  1) Firebase Console → проєкт dostavka-ed553 → Authentication → Sign-in method → увімкнути Email/Password.
  2) Realtime Database → Rules → вставити вміст database.rules.json → Publish.
     (Правила оновлені: додано розділи photos і locations. Якщо вже вставляли старі — замініть.)
  3) Залити на хостинг: index.html, sw.js, manifest.webmanifest, favicon-32.png, apple-touch-icon.png, icon-192.png, icon-512.png.
     Програма має відкриватися по https (GitHub Pages, Netlify, Firebase Hosting — так і є).
  4) Ще → Налаштування: водії з телефонами, адреса складу, тарифи доставки й підйому, телефон магазину для повідомлень.

  Після цього працюють: повідомлення клієнтам, фото й підпис, підйом і доставка в касі, часткова доставка,
  карта водіїв, звуки, офлайн-режим і сповіщення, поки програма відкрита у фоні.

2. PUSH ПРИ ЗАКРИТІЙ ПРОГРАМІ (потрібен тариф Blaze)
  Blaze — оплата за фактом. При вашому обсязі зазвичай 0 грн, бо безкоштовні ліміти великі, але потрібна картка.
  1) Firebase Console → Project settings → Cloud Messaging → Web Push certificates → Generate key pair.
     Скопіювати ключ → у програмі: Ще → «Підтвердження доставки і push» → Ключ Web Push.
  2) На комп'ютері: встановити Node.js 20 і Firebase CLI (npm i -g firebase-tools), потім у теці з архівом:
       firebase login
       firebase use dostavka-ed553
       cd functions && npm install && cd ..
       firebase deploy --only functions
     (У functions/index.js можна вписати APP_URL — адресу програми, щоб сповіщення відкривало її.)
  3) Кожен користувач на своєму телефоні: аватар → «Сповіщення телефону» → Увімкнути.
     На iPhone спершу «Поділитися → На початковий екран», і відкривати програму звідти (iOS 16.4+).

ПІДКАЗКИ
  • Звуки вмикаються/вимикаються в профілі (аватар зліва вгорі), там же можна їх прослухати.
  • Водій передає геопозицію, поки програма відкрита. Вимкнути можна в профілі.
  • Фото зберігаються в базі стиснутими (~100–150 КБ). Безкоштовного 1 ГБ вистачає приблизно на 6–8 тис. фото.
    Старі доставки разом із фото прибирає «Очищення даних за період» (спершу зберігає Excel).
  • Офлайн: якщо зв'язку немає, програма відкривається зі збереженою копією, а зміни відправляються,
    щойно з'явиться інтернет. Не закривайте програму, поки зміни не відправились (зелена точка вгорі справа).
